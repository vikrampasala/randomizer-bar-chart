# Randomizer Bar Chart

A dynamic data visualization project built with HTML, CSS, and JavaScript for college coursework. This application generates randomized data sets and renders them in real-time using an interactive, animated bar chart.

## 🚀 Features
* **Dynamic Rendering:** Instantly updates bar heights based on randomized inputs.
* **Interactive Elements:** Features a "Randomize" button to refresh the chart values on demand.
* **Modern UI:** Clean layout with smooth CSS transitions for chart animations.

## 📂 File Structure
* `index.html` - Contains the structural layout, embedded styles, and chart logic.

## 🛠️ Concepts Demonstrated
* JavaScript array generation and manipulation.
* Dynamic DOM updates to modify inline element styling (heights and data labels).
* Responsive layout design for charting components.
